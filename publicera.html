Min arbetsprocess

Webbplatsen utvecklas i en development-branch i Git för att hålla arbetet organiserat. Alla ändringar committas med tydliga meddelanden. När koden är stabil, mergas den till main/prod-branch för publicering.

Vad som är gjort

  • Skapat projektstruktur med HTML, CSS, JavaScript och bilder.
  • Installerat och konfigurerat Vite för utveckling och build.
  • Lagt till 6 bilder i src/images och visat dem på bildsidan.
  • Skapat startsida, bildsida och publicera-sida med huvudmeny och responsiv design.
  • Använt Git för versionhantering och pushat filer till GitHub.

Automatisering med NodeJS och Vite

  • CSS och JavaScript: Vite tar hand om minifiering och bundling automatiskt vid produktion (npm run build).
  • Bilder: Alla bilder optimeras och konverteras till moderna format (WebP) vid build-processen.
  • Hot reload: Under utveckling uppdateras sidan direkt i webbläsaren när filer ändras (npm run dev).
  • Kopiering: Alla färdiga filer samlas i mappen dist/ för enkel publicering.

Verktyg som används

  • NodeJS: kör Vite och alla automatiserade processer.
  • Vite: utvecklingsserver, bundling, minifiering och optimering.
  • Git & GitHub: versionshantering, branches och koppling till host för automatisk publicering.
  • Host (Vercel / Netlify / GitHub Pages): automatiserad publicering från main/prod-branch.

På detta sätt sparar man tid och säkerställer att webbplatsen alltid är optimerad och korrekt uppdaterad när ändringar görs.
